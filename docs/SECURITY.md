# Security and restricted data

This is a private course repository. Do not commit or publish the restricted
`zh-vi/` and `en-vi/` corpora, predictions containing source/reference rows,
manual annotations, checkpoints, run manifests, logs, Kaggle bundles, credentials,
or machine-local paths.

Report a suspected credential or data exposure directly to the repository owner.
Do not place the exposed value in a GitHub issue. Revoke credentials first, then
remove the material from Git history before any push.

Before every first push or history rewrite, follow `docs/GITHUB_PUBLISHING.md` and
enable GitHub push protection on the private repository when the account plan
supports it.
